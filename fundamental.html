What DAGBO checks
• Interest-rate level as a relative yield-support proxy
• GDP growth as an economic momentum proxy
• Unemployment rate as a labour-market proxy
• Inflation displayed as context, not automatically treated as bullish or bearish
• Data freshness, missing values and source coverage
How it connects to other systems

Signals use it as a context filter; News uses it to explain the currency backdrop; HTF analysis uses it as a higher-level confirmation; Smart Pair Hedge can compare both legs' macro bias. Fundamental data never overrides price confirmation by itself.
